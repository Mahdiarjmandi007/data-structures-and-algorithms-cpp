# Data Structures and Algorithms in C++

A collection of fundamental data structures and algorithms implemented from scratch in C++ for educational purposes and practice.
All implementations were built from scratch to better understand the internal mechanics of fundamental data structures and algorithms.

## Implemented Data Structures

### Circular Linked List
- Insert at beginning
- Insert at end
- Delete by value
- Circular traversal

### Heap
- Min Heap
- Max Heap
- Insert operation
- Delete operation
- Tree visualization

### Hash Table (Open Addressing)
- Linear Probing
- Insert operation
- Delete operation
- Collision handling

### Complete Binary Tree
- Level-order insertion
- Binary tree visualization
- Queue-based implementation

## Implemented Algorithms

### Binary Search
- Iterative Binary Search
